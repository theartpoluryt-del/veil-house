# Мебель Blender / Unity

Оригинальные модели для версии 0.2: диван, кресло, обеденный стул, 14 вариантов столов по размерам комнат и 3 книжных шкафа. Внешние модели и платные ассеты не используются.

`Furniture.blend` содержит расставленную библиотеку редактируемых сеток с UV и материалами. PNG связаны относительными путями с `Assets/Resources/SurfaceTextures`. Готовые FBX находятся в `Assets/Resources/Furniture`; Unity-префабы — в подпапке `Prefabs`.

У мягкой мебели есть отдельные подушки с неравномерной деформацией, небольшими складками, кантами, утяжками и деревянными рамами. Столы имеют стыки досок, фаски, царги, точёные сужающиеся ножки и, у высоких вариантов, лицевую панель ящика. Шкафы имеют профилированный карниз, каннелюры, полки и книги разной ширины и высоты. Ящики столов в этой версии декоративные; интерактивные шкафы из исходного прототипа остаются отдельными объектами.

`build_furniture.py` воспроизводит модели в Blender 5.2.1 LTS. Полная генерация занимает несколько минут; геометрия объединяется по материалам перед экспортом. Быстрое обновление выбранных моделей с повторным использованием остальных FBX:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --factory-startup --python .\SourceArt\Furniture\build_furniture.py -- --only 'Sofa,Armchair,DiningChair'
```

Без `--only` пересоздаются все модели. Размеры заданы в метрах, опора находится на уровне пола. FBX использует forward −Z / up Y; Unity-префабы разворачиваются к принятому в доме направлению −Z. `FurnitureImporter` проверяет размеры и переназначает материалы на PBR-материалы проекта. Стандартная команда сборки обновляет префабы автоматически.

Сетки доступны для чтения, поскольку WorldBuilder объединяет статические поверхности во время запуска. Для взаимодействий и проходов используются отдельные коллизии; идентификаторы 129 интерактивных объектов сохранены. Полигонаж каждого варианта указан в `Assets/Resources/Furniture/manifest.json`. Это первый набор детальной мебели: двери, кухня, сантехника, автомобиль и персонажи ещё используют исходную геометрию прототипа.
