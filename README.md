# Дом по ту сторону / Veil House

Играбельный кооперативный 3D-прототип на **Unity 6.3 (6000.3.24f1)** для Windows. Один игрок — невидимый Призрак; ещё 1–6 игроков — Детективы. Призрак знает обстоятельства смерти и передаёт подсказки через предметы, свет, двери и бытовую технику. Детективы заполняют личные журналы, а в конце получают очки за правильные ответы.

## Скачать и запустить

Готовый комплект находится в [релизах](https://github.com/theartpoluryt-del/veil-house/releases). Распакуйте `VeilHouse-Prototype.zip` и запустите `Windows/VeilHouse.exe`. Рядом с EXE должны оставаться `VeilHouse_Data`, DLL и остальные файлы сборки. Устанавливать Unity для готовой игры не требуется.

Для одиночного знакомства выберите **«Осмотреть дом»**, затем роль. Для игры с друзьями один участник создаёт расследование, остальные подключаются по IP хоста. Порт по умолчанию — **7777/TCP**. Поддерживается локальная сеть, общая VPN-сеть или прямое подключение к доступному порту хоста. Облачного Relay и автоматического проброса NAT нет. Для нескольких экземпляров на одном ПК используйте `127.0.0.1`.

Матч длится восемь минут; хост может закончить его раньше через Esc. После раскрытия истории и результатов можно вернуться в лобби и начать новое дело.

## Открыть исходники

1. Клонируйте этот репозиторий.
2. Добавьте его корневую папку в Unity Hub и выберите **6000.3.24f1** с модулем Windows Build Support.
3. Откройте `Assets/Scenes/VeilHouse.unity` и нажмите Play.

Дом собирается при запуске из импортированных моделей и процедурных деталей; звуки синтезируются кодом. В версии 0.4 используются 31 материал со 124 картами 2048×2048: дерево, отделка стен и полов, ткани, керамика, металлы, резина, камень, растительность и другие поверхности. Каждый набор содержит цвет, нормали, Metallic/Smoothness и Occlusion; маска загрязнения меняет цвет и шероховатость. Материалы находятся в `Assets/Resources/Materials`; текстуры — в `SurfaceTextures`.

Исходная библиотека Blender и генератор находятся в [SourceArt/Materials](SourceArt/Materials/README.md). Blender не требуется для запуска или сборки игры: готовые PNG и материалы включены в репозиторий. Проект использует встроенные модули Unity; дополнительные аккаунты, ключи API и платные ассеты не нужны. Команда редактора **Veil House → Build Windows prototype** сохраняет сборку в папку `Windows` рядом с папкой проекта.

Диван, кресла, обеденные стулья, столы и книжные шкафы заменены моделями из Blender: отдельные подушки, швы и складки, стыки досок, фаски, точёные ножки и профилированная отделка. Исходники, FBX и описание процесса: [SourceArt/Furniture](SourceArt/Furniture/README.md). Всего 20 вариантов моделей под размеры существующих комнат.

Обновление 0.3 добавляет ещё **77 моделей**, заменяющих 224 размещённых предмета: посуду, вазы, светильники, фотографии и картины, часы, растения, двери и окна, шкафы и кровати, сантехнику, бытовую технику, автомобиль и гаражные принадлежности. У шкафов открываются отдельные створки, у ламп работает свечение; сохранены 129 сетевых объектов и физика 90 переносимых предметов. Генераторы, редактируемые `.blend`, результаты проверки экспорта и список категорий: [SourceArt/Props](SourceArt/Props/README.md).

Обновление **0.4** переделывает освещение: почти нулевой ambient, локальные лампы с тенями, 372 light probes с ночным и освещённым состояниями, восемь обновляемых reflection probes, SSAO, экранные контактные тени, HDR tonemapping и слабый bloom. Планировка сжата по горизонтали до 78%, потолок опущен до 3 м. Добавлены 18 моделей и 96 бытовых деталей — по 10–15 на зону, профилированные плинтусы, пороги и радиаторы. Всего доступны 115 моделей предметов и мебели. Фонарик включается клавишей **F** у Детектива. Подробности и перезапекание: [свет и интерьер](SourceArt/ATMOSPHERE.md).

## Управление

| Действие | Клавиша |
|---|---|
| Движение / обзор | WASD / мышь |
| Взаимодействие | E |
| Личный журнал / история Призрака | Tab |
| Помощь / меню | F1 / Esc |
| Детектив: бег / присесть | Shift / Ctrl |
| Детектив: фонарик / текстовый чат | F / Enter |
| Призрак: вверх / вниз | Space / Ctrl |
| Призрак: поднять / отпустить предмет | E |
| Призрак: бросить / отпустить | ЛКМ или F / ПКМ |
| Призрак: встряхнуть предмет | R |
| Призрак: полтергейст / отключение света | Q / C |

Воздействия расходуют восстанавливающуюся энергию. В журнале выбор сохраняется сразу; повторный выбор того же ответа не сбрасывает время. При равенстве очков выигрывает меньшая сумма времени фиксации верных ответов.

## Состав проекта

- Восемь зон: гостиная, кухня, кабинет, две спальни, ванная, галерея и гараж.
- 129 интерактивных объектов, включая 90 физических предметов.
- 20 заранее составленных совместимых историй; категории и варианты хранятся в `Assets/Resources/storybook.json`.
- Отдельные модули сети, взаимодействий, расследования, персонажей, звука и интерфейса.
- Физика предметов рассчитывается хостом; клиенты получают снимки состояния. До раскрытия выбранная история передаётся только Призраку.
- Оригинальные skinned-модели Детективов с Humanoid-скелетом и программными анимациями.

Структура и план реализации: [IMPLEMENTATION.md](IMPLEMENTATION.md). Происхождение ресурсов и промпт семейного портрета: [ASSET-PROVENANCE.md](ASSET-PROVENANCE.md). Шрифты Noto распространяются по [SIL OFL](FONT-LICENSE.txt).

## Проверки и ограничения

Проект собран и запущен в Windows. Полный цикл, скрытие истории, журналы, очки, синхронизация 129 объектов и повторный матч проверены на хосте и двух графических клиентах. Отдельные 20 проверок правил и TCP включают вместимость семи участников и отказ восьмому. Проверены 20 точек маршрута через комнаты и валидность Humanoid-скелета. Отчёты, снимки и команды повторения входят в папку `Verification` в архиве релиза.

В версии 0.4 выполнены 379 автоматических проверок готовой игры: 266 проверок предметов и взаимодействий, 38 проверок материалов/мебели/персонажа, 20 точек маршрута, 13 проверок освещения и 42 проверки сетевого матча. Все прошли без ошибок. Снимки 129 объектов и итоговые очки обоих клиентов совпали с хостом. Проверены экспорт новой категории Household (18 моделей), обновлённая библиотека мебели (20 моделей) и переносимость 12 библиотек Blender. Отчёты и реальные кадры находятся в `Verification/Atmosphere-v0.4.0` архива.

Это прототип основного игрового цикла. Встроенного голосового чата, облачного Relay, миграции хоста, сохранений матчей и восстановления соединения нет. Голосовая связь — через внешний сервис. Полноценный матч семи людей на разных компьютерах и подключение через интернет ещё требуют проверки; баланс подсказок требует живых игровых сессий.
